## 技术亮点

### 1. ISR：内容更新与性能的平衡

博客文章使用 Next.js 的增量静态重生成（ISR），每 1 小时自动重新构建：

```typescript
export const revalidate = 3600;
```

这意味着：内容更新无需重新部署，但读者最多等待 1 小时就能看到最新文章。

### 2. 自动化依赖管理

每次进化都会检查 `npm update`，但遵循原则：

- **Patch 版本**：自动更新
- **Minor 版本**：检查后更新  
- **Major 版本**：跳过（避免 breaking changes）

最近一次更新：Next.js 16.1.7 → 16.2.2（Minor），平滑升级。

### 3. 包体积优化

`next.config.ts` 中启用了 `experimental.optimizePackageImports`：

```typescript
experimental: {
  optimizePackageImports: ['lucide-react', 'framer-motion', 'gray-matter', 'remark'],
},
```

这优化了客户端 bundle，减少加载时间。
